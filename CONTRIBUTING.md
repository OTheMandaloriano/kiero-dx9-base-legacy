# Diretrizes de Contribuição

Agradecemos o interesse em contribuir com a base **Kiero DirectX 9 + Dear ImGui (Legacy)**.

Este repositório é mantido como uma referência clássica e minimalista.

---

## Como Contribuir

1. Faça um Fork do repositório.
2. Crie uma branch para sua modificação: `git checkout -b minha-melhoria`.
3. Certifique-se de que o projeto compila sem erros em `Release Win32` e `Release x64`.
4. Faça o commit utilizando mensagens convencionais em português brasileiro (`[feat]`, `[fix]`, `[refactor]`, `[docs]`, `[chore]`).
5. Abra um Pull Request detalhando a alteração.
